LLM Book Club — Setup Steps
============================

1. Open PowerShell as Administrator in the repository directory and run:
   powershell -ExecutionPolicy Bypass -File ".\setup\01_install_docker.ps1"

2. Restart your computer.

3. After restart, open PowerShell in the repository directory and run:
   powershell -ExecutionPolicy Bypass -File ".\setup\02_start_app.ps1"

4. Open http://localhost:3000 in your browser.

5. Drag a book from your computer into the upload area.
